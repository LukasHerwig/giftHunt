# Phase 5 – Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new Home at `/`: invitations on top (accept or decline inline), then "Mina önskelistor" and "Listor jag arrangerar" as rows (with a "N förfrågningar" marker on organized lists that have waiting requests), a "Ny önskelista" sheet (own list or one made for someone else), and a first-visit empty state. The old `Dashboard` and `SharedWishlists` features are removed; `/shared-wishlists` redirects to `/`.

**Architecture:** A new feature folder `src/Home/` replaces `src/Dashboard/`. Pure logic (display names, row view-models, new-list validation and insert row) is plain TypeScript with `node:test` unit tests. `HomeService` loads each section with embedded PostgREST selects (RLS decides what a user sees); `useHome` holds state and the three actions (create, accept, decline); components are Tailwind with the `gh-*` tokens, reusing `ResponsiveSheet`, `Segmented`, `TextField`, `TextArea`, `ConfirmBlock`, `StatusPill`, `EmptyState`, `SectionHeader`. One small migration adds `decline_invitation(uuid)` so an invitee can turn an invitation down.

**Tech Stack:** React 18 + TypeScript, react-router-dom, react-i18next, sonner, Tailwind (`gh-*`), Supabase (RLS, SECURITY DEFINER RPC, pgTAP via `npm run test:db`), `node:test` (`npm run test:unit`).

**Spec:** `docs/superpowers/specs/2026-10-20-ui-redesign-design.md` sections 1 and 5 (Home). Approved design: https://claude.ai/artifact/Bn2EAQs9VsGuWgpApRfYpF (9 boards: Home with invitation, organizer-only, first visit, loading, dark, new list own / for someone else, desktop home and panel). Decisions made while approving it: invitations have **Bli arrangör** and **Nej tack**; organized rows show **N förfrågningar** when requests wait; a new list starts with **only links on** (price and priority off, as today) and the three switches live in Settings; there is no switch row in the create sheet.

## Global Constraints

- Never hardcode user-facing strings: keys in `src/locales/en.json` and `sv.json` (Swedish copy per the canvas, but never gendered: "{{name}} vill att du delar listan…", not "åt henne"), through `useTranslation()`.
- Only `gh-*` Tailwind tokens; one primary button per screen state (invitation "Bli arrangör", or "Skapa din första önskelista" on the empty state, or "Skapa önskelista" in the sheet); touch targets ≥ 44px; text ≥ 12px; inline `ConfirmBlock` for a destructive question (declining an invitation); components defined at module top level.
- Data stays behind RLS: Home only reads what the signed-in user may read; no new broad grants. `decline_invitation` is SECURITY DEFINER, checks the caller's confirmed e-mail like `accept_invitation`, and is not callable by `anon`.
- Generated links use `getBaseUrl()` (none are needed here). Navigation after create goes to `/wishlist/:id`.
- A second tap while an action runs is ignored (ref guard in the hook), as in the Wishlist hooks.
- Pure logic imports types with `import type` and `.ts` extensions in relative imports so `node --test` runs it.
- Baselines before this phase: `tsc` has 1 pre-existing error (`src/Dashboard/components/index.ts:7`, which disappears with the deleted folder), `npm run lint` 10 problems (3 errors, 7 warnings); neither may grow.

## Review Focus

- **Declining an invitation** is only possible for the person it is addressed to (confirmed e-mail), never for the owner, a stranger or `anon`, and not after it was accepted. After a decline the owner can invite again. (Task 1 pgTAP)
- **Accept/decline races:** the owner withdrew or replaced the invitation, it expired, the list already has an organizer: a clear toast and a reload, never a stuck card. (Task 3 hook, Task 5 browser)
- **What each section lists:** owned lists include self-managed ones (marked "Du delar listan"); "Listor jag arrangerar" never includes a list the user created; an invitation is not also listed as an organized list. (Task 2 tests, Task 5 browser)
- **Requests marker** counts only pending requests on lists the user organizes, never on their own lists. (Task 3, Task 5)
- **New list:** title required (no whitespace-only), "Åt någon annan" creates a self-managed list and makes the creator its organizer in the same flow, rolled back if the admin row fails; defaults are links on, price and priority off. (Task 2 tests, Task 3)
- **Nothing still imports the deleted code** (`Dashboard`, `SharedWishlists`), `/shared-wishlists` redirects, and every `home.*` key used exists in both languages. (Task 5)

```sql
-- An invitee can turn an invitation down. Only the owner could delete invitations
-- before, so a declined invitation would have stayed (and blocked inviting
-- someone else, since a list has at most one invitation). Same identity checks as
-- accept_invitation: the invitation must be addressed to the caller's confirmed e-mail.
create or replace function public.decline_invitation(p_invitation_id uuid)
returns void language plpgsql volatile security definer set search_path = public as $$
declare
  v_inv admin_invitations%rowtype;
begin
  select * into v_inv from admin_invitations where id = p_invitation_id for update;
  -- is distinct from: a JWT without an email claim must not pass the check.
  if not found or lower(v_inv.email) is distinct from lower(auth.jwt() ->> 'email') then
    raise exception 'invitation_not_found' using errcode = 'P0002';
  end if;
  if not exists (select 1 from auth.users
                 where id = auth.uid() and email_confirmed_at is not null) then
    raise exception 'email_not_confirmed' using errcode = 'P0001';
  end if;
  if v_inv.accepted then
    raise exception 'already_accepted' using errcode = 'P0001';
  end if;

  delete from admin_invitations where id = p_invitation_id;
end;
$$;

revoke execute on function public.decline_invitation(uuid) from public, anon;
grant execute on function public.decline_invitation(uuid) to authenticated, service_role;
```

```ts
  OrganizedRow,

/** The name to show for a person: full name, else e-mail, else nothing. */
export const displayName = (profile: ProfileName | null): string | null => {
  if (!profile) return null;
  const name = profile.full_name?.trim();
  if (name) return name;
  const email = profile.email?.trim();
  return email ? email : null;
};

export const firstName = (fullName: string | null | undefined): string | null => {
  const name = fullName?.trim().split(/\s+/)[0];
  return name ? name : null;
};

export const toOwnedRows = (lists: OwnedListRaw[]): OwnedRow[] =>
  lists.map((list) => ({
    id: list.id,
    title: list.title,
    itemCount: list.itemCount,
    // On a self-managed list the "organizer" is the owner themselves.
    organizerName: list.is_self_managed ? null : displayName(list.organizer),
    selfManaged: list.is_self_managed,
  }));

export const toOrganizedRows = (lists: OrganizedListRaw[]): OrganizedRow[] =>
  lists.map((list) => ({
    id: list.id,
    title: list.title,
    ownerName: displayName(list.owner),
    itemCount: list.itemCount,
    requestCount: list.requestCount,
  }));

export const toInvitationRows = (invitations: InvitationRaw[]): InvitationRow[] =>
  invitations.map((invitation) => ({
    id: invitation.id,
    title: invitation.title,
    inviterName: displayName(invitation.inviter),
  }));
```

```ts
import { supabase } from '@/integrations/supabase/client';
import { toNewListRow } from '../lib/newList';
import type {
  HomeData,
  InvitationRaw,
  NewListForm,
  OrganizedListRaw,
  OwnedListRaw,
  ProfileName,
} from '../types';

type CountRow = { count: number }[] | null;
const countOf = (rows: CountRow): number => rows?.[0]?.count ?? 0;

export class HomeService {
  static async loadHome(userId: string, email: string): Promise<HomeData> {
    const [owned, organized, invitations] = await Promise.all([
      HomeService.loadOwned(userId),
      HomeService.loadOrganized(userId),
      HomeService.loadInvitations(email),
    ]);
    return { owned, organized, invitations };
  }

  /** Lists the user made, including ones made for someone else; item count and organizer in one query. */
  private static async loadOwned(userId: string): Promise<OwnedListRaw[]> {
    const { data, error } = await supabase
      .from('wishlists')
      .select(
        'id, title, description, is_self_managed, created_at, items:wishlist_items(count), admins:wishlist_admins(profile:profiles!admin_id(full_name, email))',
      )
      .eq('creator_id', userId)
      .order('created_at', { ascending: false });
    if (error) throw error;

    type Row = Omit<OwnedListRaw, 'itemCount' | 'organizer'> & {
      items: CountRow;
      admins: { profile: ProfileName | null }[] | null;
    };
    return ((data ?? []) as unknown as Row[]).map(({ items, admins, ...list }) => ({
      ...list,
      itemCount: countOf(items),
      organizer: admins?.[0]?.profile ?? null,
    }));
  }

  /** Lists someone else made and the user organizes, with how many requests wait. */
  private static async loadOrganized(userId: string): Promise<OrganizedListRaw[]> {
    const { data, error } = await supabase
      .from('wishlists')
      .select(
        'id, title, description, owner:profiles!creator_id(full_name, email), items:wishlist_items(count), mine:wishlist_admins!inner(admin_id)',
      )
      .eq('mine.admin_id', userId)
      .neq('creator_id', userId)
      .order('created_at', { ascending: false });
    if (error) throw error;

    type Row = Omit<OrganizedListRaw, 'itemCount' | 'requestCount' | 'owner'> & {
      owner: ProfileName | null;
      items: CountRow;
    };
    const lists = (data ?? []) as unknown as Row[];
    if (lists.length === 0) return [];

    const { data: requests, error: requestError } = await supabase
      .from('item_change_requests')
      .select('wishlist_id')
      .eq('status', 'pending')
      .in('wishlist_id', lists.map((list) => list.id));
    if (requestError) throw requestError;
    const waiting = new Map<string, number>();
    for (const request of requests ?? []) {
      waiting.set(request.wishlist_id, (waiting.get(request.wishlist_id) ?? 0) + 1);
    }

    return lists.map(({ items, ...list }) => ({
      ...list,
      itemCount: countOf(items),
      requestCount: waiting.get(list.id) ?? 0,
    }));
  }

  private static async loadInvitations(email: string): Promise<InvitationRaw[]> {
    if (!email) return [];
    const { data, error } = await supabase
      .from('admin_invitations')
      .select(
        'id, wishlist_id, wishlist:wishlists(title, description), inviter:profiles!invited_by(full_name, email)',
      )
      .ilike('email', email)
      .eq('accepted', false)
      .or(`expires_at.is.null,expires_at.gt.${new Date().toISOString()}`);
    if (error) throw error;

    type Row = {
      id: string;
      wishlist_id: string;
      wishlist: { title: string; description: string | null } | null;
      inviter: ProfileName | null;
    };
    return ((data ?? []) as unknown as Row[]).map((row) => ({
      id: row.id,
      wishlistId: row.wishlist_id,
      title: row.wishlist?.title ?? '',
      description: row.wishlist?.description ?? null,
      inviter: row.inviter,
    }));
  }

  /** Creates the list; one made for someone else also makes the creator its organizer (undone if that fails). */
  static async createList(userId: string, form: NewListForm): Promise<string> {
    const { data, error } = await supabase
      .from('wishlists')
      .insert(toNewListRow(userId, form))
      .select('id')
      .single();
    if (error) throw error;

    if (form.kind === 'other') {
      const { error: adminError } = await supabase
        .from('wishlist_admins')
        .insert({ wishlist_id: data.id, admin_id: userId, invited_by: userId });
      if (adminError) {
        await supabase.from('wishlists').delete().eq('id', data.id);
        throw adminError;
      }
    }
    return data.id;
  }

  static async acceptInvitation(invitationId: string): Promise<void> {
    const { error } = await supabase.rpc('accept_invitation', { p_invitation_id: invitationId });
    if (error) throw error;
  }

  static async declineInvitation(invitationId: string): Promise<void> {
    const { error } = await supabase.rpc('decline_invitation', { p_invitation_id: invitationId });
    if (error) throw error;
  }
}
```

```ts
import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import { useNavigate } from 'react-router-dom';
import { useTranslation } from 'react-i18next';
import { toast } from 'sonner';
import { useAuth } from '@/components/auth/useAuth';
import { errorCode } from '@/Wishlist/lib/errorCode';
import { firstName, toInvitationRows, toOrganizedRows, toOwnedRows } from '../lib/homeRows';
import { validateNewList } from '../lib/newList';
import { HomeService } from '../services/HomeService';
import type { HomeData, NewListError, NewListForm } from '../types';

export const useHome = () => {
  const { t } = useTranslation();
  const navigate = useNavigate();
  const { user } = useAuth();
  const userId = user?.id;
  const email = user?.email ?? '';
  const [data, setData] = useState<HomeData | null>(null);
  const [loading, setLoading] = useState(true);
  const [sheetOpen, setSheetOpen] = useState(false);
  const [busy, setBusy] = useState(false);
  // A second tap while an action runs must not start a second one.
  const running = useRef(false);

  const load = useCallback(async () => {
    if (!userId) return;
    try {
      setData(await HomeService.loadHome(userId, email));
    } catch (error) {
      console.error('Load home error:', error);
      toast.error(t('home.toast.loadFailed'));
    } finally {
      setLoading(false);
    }
  }, [userId, email, t]);

  useEffect(() => {
    void load();
  }, [load]);

  const owned = useMemo(() => toOwnedRows(data?.owned ?? []), [data]);
  const organized = useMemo(() => toOrganizedRows(data?.organized ?? []), [data]);
  const invitations = useMemo(() => toInvitationRows(data?.invitations ?? []), [data]);
  const greetingName = firstName(user?.user_metadata?.full_name as string | undefined);

  const run = useCallback(
    async (action: () => Promise<void>, errorKey: string): Promise<boolean> => {
      if (running.current) return false;
      running.current = true;
      setBusy(true);
      try {
        await action();
        return true;
      } catch (error) {
        console.error(error);
        const code = errorCode(error);
        if (code === 'invitation_not_found' || code === 'already_accepted' || code === 'invitation_expired') {
          toast.error(t('home.toast.invitationGone'));
          await load();
        } else if (code === 'admin_already_exists') {
          toast.error(t('home.toast.organizerExists'));
          await load();
        } else if (code === 'email_not_confirmed') {
          toast.error(t('home.toast.emailNotConfirmed'));
        } else {
          toast.error(t(errorKey));
        }
        return false;
      } finally {
        running.current = false;
        setBusy(false);
      }
    },
    [t, load],
  );

  const createList = async (form: NewListForm): Promise<NewListError | null> => {
    const invalid = validateNewList(form);
    if (invalid) return invalid;
    if (!userId) return null;
    let id = '';
    const ok = await run(async () => {
      id = await HomeService.createList(userId, form);
    }, 'home.toast.createFailed');
    if (ok) {
      toast.success(t('home.toast.created'));
      navigate(`/wishlist/${id}`);
    }
    return null;
  };

  const acceptInvitation = async (invitationId: string) => {
    const ok = await run(() => HomeService.acceptInvitation(invitationId), 'home.toast.acceptFailed');
    if (ok) {
      toast.success(t('home.toast.accepted'));
      await load();
    }
  };

  const declineInvitation = async (invitationId: string) => {
    const ok = await run(() => HomeService.declineInvitation(invitationId), 'home.toast.declineFailed');
    if (ok) {
      toast.success(t('home.toast.declined'));
      await load();
    }
  };

  return {
    loading,
    owned,
    organized,
    invitations,
    greetingName,
    sheetOpen,
    busy,
    openSheet: () => setSheetOpen(true),
    closeSheet: () => setSheetOpen(false),
    createList,
    acceptInvitation,
    declineInvitation,
  };
};
```
